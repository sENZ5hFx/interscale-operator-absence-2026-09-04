## Primary insight

**Interscale-Operator Absence Class (IOA).** After the subtractions above, the remaining unknown is not a missing place, not a missing converter, not an insufficient named cause, not a failed settler, not a clock mismatch, and not an unjoined same-scale ledger.

It is this: **two scales of one named process are independently documented; no field owns the operator that would take a state at scale A and emit a unique, pre-registered prediction at scale B; the same English name is used at both scales, hiding the missing transport.**

The experiment that would close the gap is a *transfer function with exclusion of ordinary alternative paths*, not a new instrument, not a same-scale join.

### Operators inside IOA

1. **Dual-scale occupancy** — scale A and scale B both have published measurements of the "same" named process. A hypothesized unmeasured scale does not count. (This kill-rule zeroed "quantum gravity solves H0": Planck scale is not empirically occupied. Afshordi et al., *Physics* 19.34, 12 May 2026: ~5% of APS respondents chose QG for low-energy mysteries; concordance 3–4× random. Sociology of physics, not IOA.)
2. **Operator-absence** — no paper's *object* is the A→B transfer function.
3. **Same-name collapse** — one English word (web, communication, compass, biosignature, function) is used at both scales as if the operator were identity.
4. **Ordinary-path unexcluded** — Type I IOA holds only if at least one more-ordinary transport (diffusion, contact, artefact, byproduct) remains unexcluded in the field. Lab-only exclusion is not enough.
